# JavaDuikt

Практичні роботи з дисципліни **«Конструювання програмного забезпечення JAVA»** (ДУІКТ, 2026–2027).

| № | Тема | Папка |
|---|------|-------|
| 1 | Основи Java: консольний інтернет-магазин (Lombok) | [Practice1-OnlineShop](Practice1-OnlineShop) |
| 2 | ООП: фінансовий аналізатор банківських транзакцій з CSV (Lombok, JUnit 5) | [Practice2-FinanceAnalyzer](Practice2-FinanceAnalyzer) |

Кожна папка — окремий Maven-проєкт. Щоб запустити, відкрийте потрібну папку в IntelliJ IDEA (File → Open)
і запустіть клас `Main`. Потрібні JDK 17+ і Maven (вбудований в IDEA).

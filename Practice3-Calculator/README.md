# Практична робота 3. Калькулятор з обробкою виключень

Консольний калькулятор: користувач вводить два числа та операцію, програма виводить результат
або зрозуміле повідомлення про помилку.

## Що реалізовано
- `Calculator` — методи `add`, `subtract`, `multiply`, `divide` (по два параметри `double`, повертають `double`)
  та `sqrt` (квадратний корінь).
- Ділення на нуль — `ArithmeticException`.
- Власне виключення `InvalidInputException` — для некоректних даних: рядок замість числа,
  `NaN`/нескінченність, від'ємне число під коренем, невідома операція.
- `Main` — діалог з користувачем у циклі (вихід — `q`), блоки `try-catch-finally`;
  у `finally` виводиться «Обробку запиту завершено.».

## Тести (JUnit 5) — `CalculatorTest`
- ділення на нуль;
- невірні вхідні дані (рядки замість чисел, параметризований тест);
- випадки власного виключення (від'ємний корінь, NaN/Infinity, невідома операція);
- коректні обчислення.

## Запуск
IntelliJ IDEA: відкрити папку як Maven-проєкт → запустити `calc.Main`; тести — ПКМ по `src/test/java` → Run Tests.
Консоль: `mvn test`, `mvn compile exec:java`.
